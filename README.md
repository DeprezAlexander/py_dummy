# Dummy Python App

This repository now contains a slightly larger collection of tiny Python
modules:

- `app.py` – interactive greeter that includes the current timestamp.
- `math_utils.py` – helpers such as `fibonacci`, `moving_average`, and `normalize`.
- `text_utils.py` – simple text analytics like `word_count` and `most_common_words`.
- `reporting.py` – stitches the helper modules together to print a short report.

## Usage

```bash
python app.py
```

Follow the prompt to enter a name, or press Enter to use the default.

To see the helper modules in action:

```bash
python reporting.py
```
